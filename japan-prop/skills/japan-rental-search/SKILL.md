# 日本の不動産・賃貸探し

jp-property-finder の MCP ツールを使って、日本の物件探しを手伝う。賃貸探しを主な用途とする。

## 進め方

1. 条件を聞き取る。足りないものだけ聞く。
   - エリア（都道府県・市区町村、または通勤先の駅）
   - 賃貸か売買か。賃貸なら家賃の上限（管理費込みか）、売買なら予算
   - 間取り・広さ、駅徒歩、入居時期、ペット・楽器などの必須条件
2. `live_search_japan_properties` で検索する。賃貸は `category="賃貸"`。市区町村ごとに呼ぶ。
3. `query_local_properties` で絞り込む。賃貸では `price` が月額家賃なので、家賃の上限は `max_price`（円）で指定する。駅徒歩は `max_walk_min`、並び順は `sort_by`（`price_asc`、`walk_asc`、`newest` など）。
4. 気になる物件は `get_property_detail` で掲載元 URL を確認し、`analyze_property_hazard_and_surroundings` で浸水・土砂災害のリスクと周辺施設を調べる。
5. 候補が複数あれば `compare_properties_tool` で表にまとめる。

## 結果を伝えるときの注意

- 掲載情報は取得した時点のものです。成約済みのことも、家賃や条件が変わっていることもあるので、掲載元 URL で最新の情報を確かめるよう伝える。
- 敷金・礼金・仲介手数料・保証会社・更新料などの初期費用は、掲載元か不動産会社で確認するよう伝える。
- **ポータルサイトに載っている物件がすべてではない。** 日本では、不動産事業者（宅地建物取引業者）しか閲覧できない「非公開物件」があります。
  - 業者向けの物件情報システム（レインズなど）にだけ登録されている物件
  - 貸主・売主の意向で広告に出さない物件
  - 管理会社や地元の不動産会社が直接扱う物件
  
  このツールではこれらは検索できない。候補が少ないとき、条件が厳しいとき、人気エリアで探すときは、希望エリアの不動産会社に条件を伝えて非公開物件も紹介してもらうよう勧める。
- 物件の良し悪しを断定しない。内見や重要事項説明で確認すべき点を挙げる。
